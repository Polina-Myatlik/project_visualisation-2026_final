    Методика, ограничения и устройство кросс-фильтрации

    Период. Учитываются 3 674 просмотра за 20.07–27.09.2026. По принятому решению 81 просмотр за 28.09–02.10 исключён из всех расчётов. Исходный Excel не изменён.

    Вовлечённость. Это количество просмотров пользователя за выбранные 10 недель, а не его оценка и не средняя глубина. Границы групп основаны на квартилях распределения: Q1 = 19, Q3 = 50. Низкая группа включает 26 пользователей, средняя 50, высокая 25. Из-за одинаковых значений на границах группы не обязаны иметь одинаковый размер.

    Тренеры. Количество просмотров делится на число доступных тренировок тренера в выбранном контексте. В знаменатель входят и доступные тренировки без выбранных просмотров. Для фильтра недели учитываются тренировки, открытые не позже конца этой недели. Фильтр группы пользователей не уменьшает число доступных тренировок. Средняя глубина и оценка считаются по отдельным просмотрам; отсутствующие оценки исключаются из среднего рейтинга.

    Кандидаты для проверки. Наш рабочий порог: средняя глубина меньше 90% при не менее 5 просмотрах. Для каждой тренировки показаны число просмотров, средняя глубина, средний рейтинг и число оценок. Низкий рейтинг на одной-двух оценках не является достаточным основанием для перезаписи. Поздние тренировки имели меньше времени на набор просмотров.

    Предпочтения. Доля типа = просмотры этого типа в группе / все выбранные просмотры группы. В подсказке также указаны абсолютное число просмотров, число активных пользователей и просмотры на пользователя. При фильтре одного типа его доля среди оставшихся просмотров станет 100%; снимите фильтр типа, чтобы сравнить предпочтения.

    Фильтры. Неделя, тип, тренер, группа и конкретная тренировка сочетаются по условию «и». Все четыре графика, показатели и список кандидатов используют одну и ту же выборку. График 3 используется для просмотра и не задаёт фильтры. График 4 позволяет выбрать группу и тип нажатием на ячейку. Для смены фильтра можно нажать другую категорию на графике 1, 2 или 4, для снятия — выбранную категорию ещё раз или крестик над графиками. Масштаб основного графика постоянный; выборка может давать пустой результат. Показатель матрицы меняет способ сравнения, а не набор записей.

    Конфиденциальность. Исходные ID пользователей не включены в файл и не отображаются. Для расчёта уникальных участников используются технические порядковые ключи без показа в интерфейсе.

    Графики показывают наблюдаемые связи. Они не доказывают причинное влияние тренера или типа на вовлечённость. Оценки оставлены добровольно и могут не отражать мнение всех участников.
